# 取得元の整理

確認日: 2026-11-08（WebFetch / 検索で確認できた範囲。「未確認」は未確認）。
共通ルール: 公開ページのみ、`robots.txt` を尊重、UA に連絡先、1 サイトあたり最低 2 秒間隔、取得内容は `source` に URL・取得日時・ハッシュで保存。ログイン必須・スクレイピング禁止明記のサイトは使わない。**画像は取得しない**（escape.id の `imageUrl` を含む。画像は全てユーザーが撮った写真のみ）。

## 1. escape MCP（escape.id）

| 取れる | 取れない |
|---|---|
| 公演名・主催（名前/ページ/サイト）・会場（名/都道府県/住所）・期間・人数・所要・制限時間・type・説明・公式 URL（`get_event`）。`imageUrl` も返るが**保存しない** | 終了公演の**検索**（`search_events` は掲載中のみ） |
| 日程スロット・空き（`list_dates`、過去 from でも periods は返る） | 参加の有無・結果・履歴（`/me/` 禁止） |
| 掲載中公演の検索（keyword / organizers / areas / 期間） | LINE 謎・Web 謎・持ち帰り・出店の大半 |
| ナゾトキマーケットの開催回（`SCRAP-org/e-nazomarket2026`） | その出展者一覧 |
| ルーム型・常設（掲載があれば）: ラベル「ルーム型」「カフェ型」等、開始日のみ・期間「-」の表示（例 `takarush-org/e-room666/`、`mayudama-org/e-ORDERsheet/`） | escape.id に載せていない団体の常設ルーム（SCRAP の通常公演・常設店は団体ページに無く、即売会 2 件のみ） |

- **使い方**: ユーザーが URL を渡す → `get_event(url)` → run + work（候補付き）の提案。終了公演 URL でも試す（未検証だがページは残っている）。
- 規約: robots は `/me/` のみ禁止。利用規約に「提供目的を超えた利用」「BOT 不正操作」「合理的範囲超過」あり。**個人利用・低頻度・ユーザー指定 URL のみ**に留める。ESCAPE.ID Hub への相談・申請は行わない（決定）。escape-mcp の `fetcher/` は差し替え可能な構造だが、移行の予定は持たない。
- 判定: **可（条件付き）**。

## 3. 自動 / 手入力の範囲

| 項目 | 自動 | 手入力 |
|---|---|---|
| 作品名・形式・団体・会場・期間・公式 URL（escape.id 掲載） | ◎ URL から | URL を渡す |
| 作品名等（escape.id 非掲載: LINE/Web/持ち帰り） | ○ 公式 URL から WebFetch | URL とタイトル |
| 団体の正式名・サイト | ○ | 改名の事実 |
| 販売先（BOOTH 等） | △ URL 単発 | URL |
| ゲームマーケット出展（団体・ブース番号） | ○ 開催回を指定して一覧取得 | どの回を取るか |
| ナゾトキマーケット出展 | △ 開催回のみ escape.id から | ブース |
| 参加の有無・ステータス・日時・結果・同行者・感想・購入 | ✗ | **全て** |
| 再演/別会場の同一作品判定 | ○ 候補提示 | 最終判断 |
| ルーム型・常設の作品と店舗 | △ escape.id 掲載分は URL から。店舗公式サイトは URL を渡せば WebFetch | 店舗 URL、載っていない作品 |
| 難易度・物量・ジャンル・メモ・写真 | ✗ | **全て**（写真はユーザー撮影のみ） |

## 4. 取得時の記録（source）

`url / domain / method / fetched_at / content_hash / excerpt(≤500 字) / robots_checked`。提案の各フィールドが `source_id` を指す。本文全文は保存しない（著作物の複製を避ける）。
